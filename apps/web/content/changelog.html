Code2Img is built in public phases, each one deployed to the same instance. This is what is live today, newest first.

15 November 2026 — Phase 6: the design system, and this site

One set of tokens (colour, type, spacing, dark and light) now drives the editor, the dashboard and every marketing page. The editor's action bar sits on a single control height with labels on one baseline, the preview card is measured and centred in its stage, and the exported frame matches the preview exactly. Code2Img got a mark of its own: an SVG logo, a favicon set (SVG, ICO, 32, 192, 512, apple-touch), a web manifest and a default Open Graph image, all generated from the product's own render service. The landing, pricing, API, blog, changelog and legal pages are here, in English and French where they need to be.

15 November 2026 — Phase 5.5: code2img.app, with HTTPS

The domain is served by the same box that runs the render service, behind a reverse proxy with Let's Encrypt certificates for code2img.app, www and api. The render port itself stays closed to the internet, reachable only by the web app with an internal token.

15 November 2026 — Phase 5: the MCP server

Code2Img speaks to agents now. There is a remote Streamable HTTP server at /mcp, authenticated with an API key, and a stdio package for local clients such as Claude Code and Cursor. Both call the public API, so quotas and the watermark are applied in one place. Setup snippets per client are on the MCP page; llms.txt is the short map an agent reads first.

15 November 2026 — Phase 4: the public API

/api/v1 went live: hashed API keys with scopes, rotation and revocation, quotas per key and per IP in Redis, idempotency keys, RFC 9457 problem responses, signed render URLs, the background and logo upload endpoints, an OpenAPI 3.1 specification with an interactive reference, and a typed TypeScript SDK.

15 November 2026 — Phase 3: share pages

Every export can become a public page at /i/<slug> with its own Open Graph, Twitter and Farcaster preview, a share bar for eleven networks, and links that expire and can be deleted by their owner.

15 November 2026 — Phase 2: accounts, plans and billing

Sign-in by magic link, entitlements, Stripe in test mode, and the Pro features behind them: no watermark, 4× exports, uploads, more presets. A dashboard for keys, presets, exports and plan state.

15 November 2026 — Phase 1: the editor and the pipeline

The monorepo, the editor, and the single render service both the preview and the download use: Shiki highlighting, a headless browser, and one definition of what a card looks like.
